# SRT 视频重排剪辑器

两种用法（前端上传时可按需选择模式，互不影响）：

1. **AI 智能切片**：上传完整直播视频 + 完整 SRT，按女装带货提示词生成多个开头钩子，
   选一个后自动重排成 46~60 秒切片 SRT，再按时间戳剪出成片。
2. **手动重排剪辑**：直接上传一份已经重排好的 SRT，工具按时间戳截取并拼接，不调用 AI。

只认时间戳，不改写文案；原视频永远不会被修改。

## 功能

- 上传原视频 + 完整 SRT，AI 生成 3~6 个开头钩子供选择
- 按「给需求 → 给价值 → 给福利 → 给信任 → 给稀缺」重排成 55~60 秒切片 SRT
- **候选片段库**：AI 生成成片时，同步产出所有满足要求的有用片段（比成片更宽）
- **成片编排**：可在候选片段库中替换成片中的片段，可在任意一条下方插入新片段（带搜索），
  也可自由调整成片顺序、删除、追加
- **片段快预览**：每一段（含候选库）都能点「▶ 预览」先看画面，
  后端按需渲染 720p 小样并缓存，不占额外磁盘
- **导出全部片段（含候选库）**：把成片段 + 候选库里的每一段都渲染成独立 mp4，
  附带文本清单 `.txt` 打包下载，方便自己在剪辑软件里二次挑素材
- 切片 SRT 完全沿用原片时间戳，不重建时间轴
- 自动解析 SRT（UTF-8 / BOM / GB18030）
- 按 SRT 时间戳计算切点，按 30fps 等整帧对齐
- 同时输出：
  - `merged.mp4`：按 SRT 顺序拼接的完整成片
  - `clips/`：与 SRT 条目一一对应的全部片段
- 网页内预览、单独下载、打包下载、取消任务
- 本地处理，不上传云端，不需要数据库

## 使用步骤

上传时可以选两种模式，按需要二选一：

### 模式一：AI 智能切片

1. 拖入原始完整视频
2. 拖入完整直播 SRT
3. 点击「上传并生成开头钩子」，等待 AI 生成开头钩子（30~120 秒）
4. 选一个钩子，点击「用这个开头生成切片 SRT」
5. 在「成片编排」区，可按需替换片段、调整顺序、删除或追加候选片段
6. 检查切点预览和警告
7. 按需调整前后余量、音频淡化、画质档位
8. 点击「开始剪辑」
9. 完成后预览/下载成片、全部片段和 `clip.srt`
10. 想要候选库里的素材也能单独拿到，点「导出全部片段（含候选库）」，
    完成后下载 `all_segments.zip`（内含每段 mp4 + `all_segments.txt` 清单）

### 模式二：手动重排剪辑（不调用 AI）

1. 拖入原始完整视频
2. 拖入已经重排好顺序的 SRT
3. 点击「上传并直接生成切点」，工具按 SRT 时间戳直接计算切点
4. 按需调整前后余量、音频淡化、画质档位
5. 点击「开始剪辑」，完成后预览/下载成片和全部片段

> AI 模式下若不想用 AI，也可在钩子面板点「跳过 AI，直接用原 SRT」；
> 手动模式下也可随时点「改用 AI 生成开头钩子」切回 AI 流程。


## 默认规则

- **无余量**：默认严格按 SRT 时间戳，只做整帧对齐
- 起点向下取整、终点向上取整，最多多出 1 帧（约 33ms），保证不丢帧
- 设置前后余量后，如果两条字幕间隔不足，会按中点共享切点，避免重复
- 顺序完全以 SRT 为准，原片时间戳只决定从哪里切
- 音频淡化默认关闭，可改为 15ms / 30ms 消除拼接咔哒声
- 极速模式按关键帧切，切点可能偏移 1–2 秒，仅用于快速预览

## 输出目录

```text
data/jobs/<任务ID>/
├── input/            # 上传的源文件
├── clips/            # 全部片段，文件名为 序号_起止时间.mp4
├── clip.srt          # AI 生成的切片字幕（沿用原片时间戳）
├── hooks.json        # 候选开头钩子与模型信息
├── merged.mp4        # 成片
├── clips.zip         # 全部片段压缩包（只含成片切出来的段）
├── export_all/       # “导出全部片段（含候选库）”渲染出的每段 mp4
├── all_segments.txt  # 导出清单（编号/来源/类型/时间/文案）
├── all_segments.zip  # 导出压缩包（clips/ 下全部 mp4 + 清单）
├── plan.json         # 切点规划明细
└── job.log           # 处理日志
```

### 磁盘占用与自动清理

每个任务都会完整保留一份上传的源视频（一个 1100 秒的 mov 就 1.6G），
所以历史任务很容易把磁盘吃满（之前堆到 19G）。现在的策略：

- **每次上传新任务后，自动只保留最近 3 个任务**，更旧的目录直接删掉
  （任务状态不持久化，重启本来也不会恢复，留旧目录纯属占地方）；
- 保留数量可用环境变量调：

```bash
SRT_CUTTER_KEEP_JOBS=2   # 默认 3；设为 1 就只留当前任务
```

- "下载片段"打包 zip 时如果磁盘不够，会返回中文提示（HTTP 507），
  不会再报 500，也不会留下半截损坏的 zip；
- 想手动清空历史数据：`rm -rf data/jobs/*`（正在跑的服务需重启后才会重新建任务）。

## 常见问题

**提示 ffmpeg 不可用**

```bash
brew install ffmpeg
```

**上传大视频很慢**

上传是本机文件拷贝，271MB 视频通常需要几秒。处理时间取决于时长、分辨率和画质档位；5 分钟竖屏视频通常 1–3 分钟。

**成片时长和 SRT 总时长不完全一样**

因为切点对齐到了整帧，单段最多多 1 帧；如果设置了余量，还会额外增加余量时长。

**极速模式切点不准**

`-c copy` 只能从关键帧开始切，这是编码格式决定的。需要精确切点请使用默认的精确模式。
